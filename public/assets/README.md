# Local Media Replacement Guide

This project intentionally ships without copyrighted film stills.

Add your own local files in this folder with these exact names to replace placeholders automatically:

- `yang-family.jpg` → Evidence Locker Asset 1 (Yang / family scene)
- `memory-light.jpg` → Evidence Locker Asset 2 (memory archive / light / nature)
- `jake-archive.jpg` → Evidence Locker Asset 3 (Jake viewing Yang's memories)
- `poster.jpg` → Optional fallback still for File 1 multimedia box if YouTube is blocked

## Recommended formats
- `jpg` or `png`
- Width: 1600px+ for clean projection/classroom display
- Landscape orientation for best fit in the archive cards

## Trailer fallback note
The app attempts to embed the official trailer via YouTube iframe.
If your school network blocks YouTube, keep the caption and replace the section with your local still (`poster.jpg`) or a teacher-approved short clip.
